Privacy policy

Accounting Pronoia is an internal tool of Pronoia AI Consulting (SAS, Paris), used only on the company's own Google account.

Data accessed

With the account owner's consent, the tool reads Gmail messages to find supplier invoices and saves their attachments to the same account's Google Drive. It also manages the company's own Apps Script project.

Use and sharing

Data is used only to file the company's invoices. It is not sold, shared with third parties, or used for advertising. Nothing is stored outside the company's own Google account.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
